## Purpose of the Study

This study investigated how **interface complexity affects cognitive load** and task performance. We compared two interface designs:

- **Interface A (Simple)**: Progressive disclosure with minimal choices
- **Interface B (Complex)**: Multiple simultaneous information displays

### Research Questions

1. Does interface complexity significantly impact task completion time?
2. Does cognitive load differ between simple and complex interfaces?
3. How does perceived usability (SUS) correlate with interface complexity?

---

## What We Found

Based on analysis of **10 participants**:

### 📊 Key Results

| Metric              | Interface A | Interface B | Significance   |
| ------------------- | ----------- | ----------- | -------------- |
| **Completion Time** | 12.93s      | 27.18s      | ✅ p = 0.031   |
| **Mental Demand**   | 1.20        | 3.60        | ✅ p = 0.003   |
| **Temporal Demand** | 0.90        | 2.60        | ✅ p = 0.001   |
| **Frustration**     | 0.40        | 2.50        | ✅ p = 0.005   |
| **SUS Score**       | 66.8        | -           | Grade C (Okay) |

### 📈 Key Insights

- 🏆 Interface A reduced task completion time by **52.4%**
- 🧠 Mental demand was **66.7% lower** with Interface A
- 😤 Frustration was **84% lower** with Interface A
- ⭐ System Usability Score: **66.8** (Grade C - Okay)

### 🎯 Interpretation

The results suggest that **simple interfaces with progressive disclosure**:

1. Significantly **reduce task completion time**
2. Lower **cognitive load** (mental demand, temporal demand)
3. Reduce **frustration**
4. Improve **perceived performance**

**Conclusion**: Interface complexity has a significant impact on cognitive load and task performance. Simple, well-organized interfaces lead to better user experience and efficiency.

## Theoretical Background

### Cognitive Load Theory (Sweller, 1988)

Cognitive load theory suggests that learning and task performance are affected by the amount of information processing required. Three types of cognitive load exist:

1. **Intrinsic Load**: Complexity inherent to the task
2. **Extraneous Load**: How information is presented
3. **Germane Load**: Mental effort for learning

Our findings suggest that **complex interfaces increase extraneous cognitive load**, leading to:

- Longer task completion times
- Higher mental demand
- Increased frustration

### NASA-TLX (Hart & Staveland, 1988)

The NASA Task Load Index is a multi-dimensional scale assessing:

- Mental Demand
- Physical Demand
- Temporal Demand
- Performance
- Effort
- Frustration

Our results show **significant differences** in 4 of 6 dimensions.

### System Usability Scale (Brooke, 1996)

SUS is a reliable tool for measuring perceived usability:

- **Score > 68**: Above average usability
- **Score 50-68**: Average
- **Score < 50**: Below average

Our **SUS score of 66.8** indicates average usability, with room for improvement.
